# Food Delivery System — DSA Project

## About
A C++ console-based food delivery system developed to practise Data Structures and Algorithms.

## Features
- Place, view, search, and cancel orders
- Add, remove, search, and display riders
- Assign riders to orders
- Update delivery status
- View delivery history
- Sort orders by order ID

## Data Structures and Algorithms
- **Queue:** Stores customer orders
- **Stack:** Stores delivery history
- **Linked List:** Manages delivery riders
- **Searching:** Finds orders and riders
- **Bubble Sort:** Sorts orders by ID

## Technologies
- C++
- Data Structures and Algorithms

## How to Run
Compile `food_delivery_system.cpp` using a C++ compiler and run the resulting program.
